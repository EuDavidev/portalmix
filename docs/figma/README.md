# PortalMix Supermercado — Figma

[Abrir o arquivo editável](https://www.figma.com/design/803LT0m1jCqBr1uFxHYHJH?node-id=5-163)

Arquivo criado na equipe **Daviii_ _'s team**. Páginas: **00 · Componentes**, **01 · Desktop** e **02 · Mobile**.

## Telas

Cada formato contém nove telas: cadastro vazio, cadastro preenchido, erros de validação, revisão, conclusão, ajuda, privacidade, confirmação de limpeza e como funciona. Total: **18 telas**.

Desktop usa largura de 1440 px; celular, 390 px. As telas principais mostram a página completa; os diálogos representam uma janela de 1024 px no desktop e 844 px no celular.

## Protótipo

Abra a página Desktop ou Mobile e use Present. Há pontos de início no cadastro vazio e nos dados de exemplo. Clicar em um campo no estado vazio ou com erros mostra o exemplo preenchido; o protótipo não recebe entrada real de texto.

Revisar avança ao resumo, Editar volta ao preenchimento e Concluir abre a confirmação. Ajuda, privacidade e limpeza têm navegação; fechar ou cancelar retorna à tela anterior. Confirmar limpeza e reiniciar voltam ao cadastro vazio.

## Organização e verificação

- Textos, ícones SVG, quadros com Auto Layout e instâncias são editáveis; nenhuma tela usa uma imagem achatada como interface.
- 23 componentes de origem, quatro conjuntos de variantes, variáveis de cor e espaçamento e estilos de texto compartilhados.
- Paleta vermelho-alaranjada e fundo creme, com erros em vinho.
- As fontes de sistema do site não estão disponíveis no ambiente Figma. **Open Sans** é a substituição explícita; o código mantém Segoe UI / Helvetica Neue / Arial.
- Fontes e ausência de imagens raster nas telas verificadas por inspeção da estrutura. Screenshots usados para revisão visual; círculos de progresso, transparência dos diálogos e textos longos de erro ajustados.
- O cadastro é demonstrativo. Não cria conta, não envia ofertas e não realiza compras reais.

Os arquivos `.txt` desta pasta registram trechos de construção usados pela API Figma. Eles exigem o contexto do arquivo e não são scripts autônomos de importação.
